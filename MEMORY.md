# Project memory

Краткая карта profile repository без секретов и лишних персональных данных.

## Назначение

Fulmo — профиль и portfolio-репозиторий. Русская и английская версии README являются
публичными entry points; generated files должны соответствовать каноническому источнику.

## Инварианты

- Не публиковать credentials и локальный мусор.
- Не считать локальную генерацию доказательством публикации: проверять live page отдельно.
- При изменении контактов и ссылок проверять обе языковые версии и generated artifacts.

См. CLAUDE.md, README-LOCAL.md и REVIEW.md.

# Fulmo profile — local runbook

## Быстрый цикл

1. Изменить канонический Markdown.
2. Проверить обе версии README и language switch.
3. Перегенерировать DOCX, HTML и PDF штатным инструментом проекта, если они затронуты.
4. Проверить ссылки, размер файлов и отсутствие временных артефактов.
5. Открыть PR с описанием source/generated изменений.

## Публикация

После merge обновить локальный clone и проверить GitHub Pages или другой live publication
path. Этот репозиторий не требует серверного deploy; публикация и runtime rollout —
разные состояния.

## Полезные ссылки

- Правила: AGENTS.md и CLAUDE.md
- Review: REVIEW.md
- История: CHANGELOG.md
